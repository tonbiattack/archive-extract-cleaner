# archive-extract-cleaner

ZIPなどの圧縮ファイルと解凍済みフォルダを照合し、**内容が完全一致する解凍済みフォルダだけを削除候補として提示する** Windows 向け Go デスクトップアプリです。スキャンは読み取り専用で、削除は候補を選択して最終確認した場合だけ実行します。

- ZIPのみ → 残す（`KEEP_ARCHIVE`）
- 解凍済みフォルダのみ → 残す（`KEEP_DIRECTORY`）
- ZIPとフォルダの全内容が完全一致 → フォルダのみ削除候補（`DELETE_CANDIDATE`）
- 追加・不足・内容変更がある → 両方残す（`MISMATCH`）
- 対応が曖昧 → 両方残す（`AMBIGUOUS`）
- 破損・暗号化・読み取り不可・上限超過など → 両方残す（`UNVERIFIED`）

HDD側の存在確認・転送・HDD内の重複削除は行いません。詳細な仕様は [docs/SPEC.md](docs/SPEC.md) を参照してください。

## 主な機能

- Everything風の一覧画面（仮想スクロール、検索、判定フィルタ、列ソート）
- 対象フォルダの複数指定、再帰スキャン、進捗表示、中断、再スキャン
- ZIPをディスクへ展開せず、エントリをストリーミングでSHA-256比較
- ZIP内の単一トップディレクトリを除去した比較（`photos.zip` 内 `photos/a.jpg` ↔ `photos/a.jpg`）
- 削除候補のみチェック選択可能。複数選択、範囲選択、候補の一括選択
- 最終確認ダイアログに対象件数・合計サイズ・削除パスを表示
- 削除直前にZIPとフォルダを再照合し、変化があればスキップ
- 削除履歴を JSONL で保存し、GUIから開ける
- サイズ・件数・圧縮率の上限を設定ファイルで変更可能

## 動作環境

- Windows 11（x64）
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Windows 11 は通常プリインストール済み）
- ビルドする場合: Go 1.26 以上、Wails CLI v2.17.1

## ビルドと起動

```powershell
git clone https://github.com/tonbiattack/archive-extract-cleaner.git
cd archive-extract-cleaner

go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.1
wails build -clean

.\build\bin\archive-extract-cleaner.exe
```

フロントエンドは `frontend/dist` の静的ファイルをWailsが埋め込むため、Node.js や npm は不要です。

開発中は次のコマンドで起動できます。

```powershell
wails dev
```

CI（`.github/workflows/ci.yml`）では Windows 上で `gofmt`・`go vet`・`go test`・`wails build` を実行し、exe を成果物としてアップロードします。

## 使い方

1. 上部の入力欄に対象フォルダを追加するか、「フォルダを選択」で追加します。複数指定できます。
2. 「スキャン」を押します。走査中も一覧・検索・フィルタ操作は可能で、「停止」で中断できます。
3. 検索語と判定フィルタ（全件 / 削除候補 / 不一致 / 未検証 / 保持）で絞り込み、列ヘッダーでソートします。
4. 行を選ぶと右側の詳細ペインに、ZIPとフォルダの対応、一致方式、ファイル数、差分・不一致理由が表示されます。ダブルクリックまたは「エクスプローラーで表示」で場所を開けます。
5. `DELETE_CANDIDATE` の行だけチェックできます。複数選択・Shift範囲選択・「候補を全選択」が使えます。
6. 「選択項目を削除」を押すと、件数・合計サイズ・削除パスを確認するダイアログが表示されます。承認後にのみ削除します。

**実削除前に必ずバックアップしてください。** 本アプリは完全一致をできる限り検証しますが、重要なデータの唯一のコピーを削除する用途には使わないでください。

### 選択状態のルール

- チェックできるのは `DELETE_CANDIDATE` のみです。
- 選択は検索・フィルタ・ソートを切り替えても保持されます。非表示の選択項目も削除確認ダイアログに表示されます。
- 新しいスキャンを開始すると選択は解除されます。
- 削除後は選択を解除し、成功・失敗・スキップの結果を表示します。失敗した行は `UNVERIFIED` として再スキャンまで削除できません。
- 「候補を全選択」は現在の検索・フィルタ条件に一致する削除候補をすべて選択します。

## 判定と対応付け

| 判定 | 意味 | 動作 |
| --- | --- | --- |
| `KEEP_ARCHIVE` | 対応フォルダなし | ZIPを保持 |
| `KEEP_DIRECTORY` | 対応ZIPなし | フォルダを保持 |
| `DELETE_CANDIDATE` | 全ファイル・空ディレクトリまで一致 | フォルダのみ削除候補 |
| `MISMATCH` | 追加・不足・内容変更あり | 両方保持 |
| `AMBIGUOUS` | 同名候補が複数、または比較方式が複数成立 | 両方保持 |
| `UNVERIFIED` | 破損・暗号化・リンク混入・上限超過・検証中の変更など | 両方保持 |

対応付けのルール:

1. 同じ親ディレクトリ内の `name.zip` ↔ `name/` を第一候補にします。
2. ZIP内の最上位ディレクトリが1つだけの場合は、それを除去した構造とも比較します。
3. 名前一致だけでは削除候補にせず、必ず内容を検証します。
4. 名前が異なる場合は自動対応しません。複数候補は `AMBIGUOUS` です。
5. フォルダのみの項目は、各対象ルート直下のフォルダ、およびZIPと同じ親にある兄弟フォルダを対象にします。ZIPを含むコンテナフォルダ（先祖ディレクトリ）は一覧のノイズを避けるため除外します。

完全一致の条件:

- ZIP内の正規化済み相対パス集合とフォルダ内の通常ファイル／ディレクトリ集合が一致
- 各ファイルの展開後バイト列のSHA-256が一致
- 空ディレクトリも比較対象
- ZIP内の絶対パス、`..`、重複パス、大小文字衝突、Windows予約名、末尾の空白/ドット等は `UNVERIFIED`
- シンボリックリンク、ジャンクション、リパースポイントを含むフォルダは走査・削除しない
- 検証中にZIPまたはフォルダの内容が変化した場合は `UNVERIFIED`

## 削除の安全策

- スキャンと詳細表示は読み取り専用です。
- 削除対象は解凍済みフォルダのみで、ZIP本体は削除しません。
- 最終確認ダイアログで明示承認した場合のみ削除します。無確認の一括削除はありません。
- 削除直前に各ZIPとフォルダを再照合し、`DELETE_CANDIDATE` でなくなった対象はスキップします。
- 対象ルート自身、ルート外、リンク/ジャンクション混入、再解析不能な対象は拒否します。
- 削除時はフォルダを同一親内の退避名にリネームし、リンク・リパースポイントが無いことを再確認してから削除します。
- 削除処理は途中で中断できません。部分的な失敗は結果ダイアログと操作ログに残します。

操作ログ（削除日時・ID・ZIP・フォルダ・成否・エラー）:

```text
%LocalAppData%\archive-extract-cleaner\operations.jsonl
```

GUI右上の「操作ログ」からエクスプローラーで開けます。

## 設定ファイルと上限

GUI右上の「設定」から現在値と設定ファイルの場所を確認できます。初回に「設定ファイルを開く」を押すと既定値のファイルを作成します。変更後はアプリを再起動してください。

```text
%AppData%\archive-extract-cleaner\config.json
```

```json
{
  "limits": {
    "maxEntries": 200000,
    "maxTotalBytes": 68719476736,
    "maxFileBytes": 17179869184,
    "maxCompressionRatio": 1000
  }
}
```

- `maxEntries`: ZIPエントリ数、またはフォルダ内のファイル＋ディレクトリ数の上限
- `maxTotalBytes`: 展開後合計サイズの上限（既定 64 GiB）
- `maxFileBytes`: 単一ファイルの上限（既定 16 GiB）
- `maxCompressionRatio`: 合計展開サイズが 1 GiB を超える場合の圧縮率上限

上限超過は `UNVERIFIED` となり削除不可です。0 を指定した項目は既定値に戻ります。

## 役割分担

- 本アプリ: ローカルのZIPと解凍済みフォルダの照合、削除候補抽出、フォルダ削除
- 既存の E/F/G 向けコピーツール: HDDへの転送と、同一階層での重複除外
- Krokiet 等: 異なる階層をまたぐ重複整理

HDD上のデータ有無や転送は判定しません。

## MVP対象外

- 7z / RAR、暗号化ZIPの中身判定
- HDDとの比較、汎用重複ファイル検索、同期・コピー
- アーカイブ本体や任意フォルダの削除
- 無確認の自動削除、ゴミ箱移動
- 異なる名前のフォルダの自動対応（明示マッピング）

## 開発

```powershell
gofmt -w .
go vet ./...
go test ./...
wails build -clean
```

主な構成:

```text
main.go / app.go / rows.go   Wailsエントリポイント、GUI API、一覧・集計
internal/engine              走査・ZIPとフォルダの対応付け・進行通知
internal/ziparchive          ZIP構造解析、パス検証、トップ階層除去
internal/fswalk              安全なフォルダ走査（リンク追跡なし）
internal/verify              パス集合と内容の完全一致検証
internal/removal             再確認付きのフォルダ削除
internal/oplog               削除操作ログ
internal/config              上限設定ファイル
internal/winpath             Windowsパス・予約名・リパースポイント検証
frontend/dist                GUI（静的HTML/CSS/JS、ビルド不要）
```

テストは実ファイルシステムの一時ディレクトリ内でのみ破壊的操作を行い、ZIPのみ／フォルダのみ／完全一致／追加・不足・変更／破損・暗号化・CRCエラー／Zip Slip／ZIP64／日本語・空白パス／ジャンクション／検証中の変更／ドライラン無変更／削除拒否条件などを検証します。
