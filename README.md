# archive-extract-cleaner

ZIPなどの圧縮ファイルと解凍済みフォルダを照合し、**内容が完全一致する解凍済みフォルダだけを削除候補として提示する**、Windows向け Go デスクトップアプリ（開発予定）。

## 目的
ローカルでダウンロードした ZIP と解凍済みフォルダが混在するとき、アーカイブを優先して残し、転送前の不要な重複を安全に整理する。

- ZIPのみ → 残す
- 解凍済みフォルダのみ → 残す（後で既存のコピーアプリが転送）
- ZIPと解凍済みフォルダが内容まで完全一致 → 解凍済みフォルダを削除候補にする
- ZIPとフォルダの内容に差異、破損、判定不能 → 両方残し要確認
- HDD側の存在確認・転送・HDD内の重複削除は行わない

## 想定ワークフロー
1. 本ツールでスキャン・照合・削除候補レビュー
2. GUIの一覧から削除候補を選択し、再検証と確認のうえローカルの重複フォルダを削除
3. 既存の E/F/G 向けコピーツールで HDD に転送（同一階層の重複除外はそちらに任せる）
4. 異なる階層の重複は Krokiet 等で後から整理する

## 安全原則
- 初期状態は **読み取り専用**。スキャン／レポートでは何も削除しない
- ZIPとの完全一致をバイト単位で検証できた場合のみ削除候補にする
- 名前・サイズ・更新日時だけでは削除を認めない
- 実削除には明示的な操作・最終確認・再照合が必要
- シンボリックリンク、ジャンクション、判定不能、アーカイブ破損などは安全側に倒す
- 実削除前にはデータをバックアップしておくことを推奨

仕様・判定ルール・GUI/CLIの想定は [docs/SPEC.md](docs/SPEC.md) を参照。

## 開発方針
- Go / Windows 11 を初期対象にし、Everything風のGUIを主操作画面とする
- スキャン結果を表形式で表示し、検索・フィルタ・ソート・複数選択・削除前確認を行える
- GUIはWails + Web UIを第一候補とし、大量件数の仮想スクロールを必須とする。CLIは任意の補助機能とする
- 最小実用版（MVP）は ZIP に限定。7z / RAR は将来の拡張として検討
- 詳細な実装タスクは GitHub Issues で管理する
