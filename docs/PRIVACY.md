# ZipSweep プライバシーポリシー

最終更新: 2026-11-23

ZipSweep（以下「本アプリ」）は、Windows 向けのアーカイブ照合・整理ツールです。本ポリシーは、本アプリが扱う情報と、その取り扱いを説明します。

## 収集しない情報

本アプリは、開発者や第三者のサーバーへ利用状況を送信しません。アクセス解析、クラッシュレポートの自動送信、広告、利用者アカウントの仕組みはありません。

## 端末内で扱う情報

本アプリは、利用者が指定したフォルダを読み取り、アーカイブと解凍済みフォルダを照合します。照合にはファイルの内容から計算した SHA-256 を使いますが、**ファイルの内容を外部へ送信しません**。

次の情報を端末内に保存します。

| 保存するもの | 場所 | 内容 |
| --- | --- | --- |
| 設定 | `%AppData%\archive-extract-cleaner\config.json` | 上限値、並列度、連携先など |
| 整理状態 | `%AppData%\archive-extract-cleaner\triage.json` | 保存・破棄・保留の記録 |
| 操作ログ | `%LocalAppData%\archive-extract-cleaner\operations.jsonl` | 移動日時、対象のパス、成否、エラー |
| スキャンキャッシュ | `%LocalAppData%\archive-extract-cleaner\cache\` | 照合結果の再利用情報 |
| 画面設定 | `%LocalAppData%\archive-extract-cleaner\webview\` | 列幅、行の高さなど |

操作ログには対象ファイルのパスが含まれます。パスに個人名や機密情報が含まれる場合は、その点にご注意ください。

## 任意の AI 連携

AI 連携は**既定で無効**です。利用者が設定ファイルで有効にし、推薦を依頼した場合に限り、利用者が指定した接続先へ次の情報を送ります。

- アーカイブ名・フォルダ名
- 同じ親フォルダにある他の項目名
- 件数、サイズ、判定理由
- 差分の代表例（ファイル名）

**ファイルの内容そのものは送りません。** ただし、名前や理由に個人情報や機密情報が含まれることがあります。送信先のプライバシー方針は利用者が指定したサービスに従います。本アプリは特定の送信先を推奨せず、既定の接続先も持ちません。

## 外部ツールとの連携

- `.7z` / `.rar` の照合では、利用者の環境にインストールされた 7-Zip の CLI を呼び出します。7-Zip のデータ取り扱いは 7-Zip の仕様に従います。
- コピー連携を利用した場合、利用者が指定した multi-drive-copy へ対象のパスを渡します。multi-drive-copy のデータ取り扱いは同ツールの仕様に従います。

いずれも本アプリが自動で導入するものではなく、利用者が用意した外部ツールです。

## 保存した情報の削除

設定ファイルの場所はアプリ内の「設定」から、操作ログは「操作ログ」から確認できます。不要になったファイルは手動で削除できます。削除した情報は復元できません。

アンインストールしても、上記の保存先は自動では削除されません。必要に応じて手動で削除してください。
