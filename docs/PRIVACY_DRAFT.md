# ZipSweep プライバシーに関する説明（草案・未公開）

この文書は Store 申請用の**草案**です。発行者は実装と設定、配布形態、連携先を再確認し、連絡先を記載した公開 URL を用意したうえで掲載してください。本書自体は公開済みプライバシーポリシーを意味しません。

- ZipSweep の標準のスキャン・照合は、ユーザーが指定したローカルファイルを読み取って行います。ZIP の比較には SHA-256 を使います。
- 設定・整理状態・操作ログ・画面設定やキャッシュはローカルに保存されます。操作ログには対象のパス、操作結果やエラーが含まれ得ます。表示名の変更後も既存の `archive-extract-cleaner` ディレクトリを使います。パッケージ版の保存先やアンインストール時の扱いは未検証です。
- 任意の AI 連携は既定で無効です。有効にして推薦を依頼した場合、利用者が指定した接続先へアーカイブ名・フォルダ名、兄弟項目名、件数・サイズ、判定理由、差分の名前や詳細などを送ります。ファイル内容自体は含めませんが、名前や理由に個人情報や機密情報が含まれることがあります。接続先のプライバシー方針を確認してください。
- 7z / RAR の照合では、ユーザーの環境の 7-Zip CLI を呼び出します。コピー連携を利用した場合はユーザーが指定した multi-drive-copy に対象パスを渡します。これら外部ソフトのデータ取り扱いは各ソフトの設定・方針に従います。
- 設定ファイルの保存先はアプリ内の「設定」で確認できます。ログは「操作ログ」から開けます。バックアップしてから手動で削除できますが、削除すると履歴等は復元できません。
