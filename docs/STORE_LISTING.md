## 短い説明（約 200 文字）

ZIP などのアーカイブと解凍済みフォルダを内容まで照合し、完全一致したフォルダだけをごみ箱へ移動できる Windows 用ツールです。スキャンとプレビューは読み取り専用。移動は確認した項目だけで、完全削除は行いません。

## 長い説明

**ZIP が残っているなら、解凍済みのフォルダは要りません。**

ZipSweep は、ZIP・7z・RAR などのアーカイブと、その解凍済みフォルダを照合する Windows 向けのデスクトップアプリです。名前が同じというだけでは判断せず、**全ファイルの内容と空ディレクトリまで一致した組だけ**を、ごみ箱への移動候補として提示します。

### できること

- 同じ親フォルダにある `name.zip` と `name/` を自動で対応付け
- アーカイブを展開せず、エントリをストリーミングで SHA-256 比較
- 一致・不一致・未検証・曖昧を一覧で表示し、差分の理由も確認できる
- 一覧から選んだ項目だけを、Windows のごみ箱へ移動
- スキャン結果を CSV / JSON へ書き出し
- 整理後に残ったデータを、別ツール（multi-drive-copy）へ引き渡し

### 安全のための設計

- **完全削除はしません。** 削除はごみ箱への移動だけで、ごみ箱が使えない環境では中止して理由を表示します
- **移動の直前に再照合します。** スキャン後にファイルが変わっていれば移動しません
- **スキャンとプレビューは読み取り専用です。** ファイルを変更しません
- **迷う要素があれば両方残します。** 破損・暗号化・リンク混入・上限超過は「未検証」として候補にしません
- **ZIP は勝手に消しません。** 既定はフォルダのみの移動です

### 動作環境

- Windows 11（x64）
- WebView2 Runtime（Windows 11 は通常プリインストール済み）
- `.7z` / `.rar` の照合には [7-Zip](https://www.7-zip.org/) の CLI が必要です。未導入の場合は「未検証」として両方を保持し、削除候補にしません

### ご注意

- **重要なデータは事前にバックアップしてください。** ごみ箱への移動はバックアップの代わりになりません
- ごみ箱へ移した容量は、ごみ箱を空にするまでディスクの空き容量として戻りません
- 本アプリは、重要なデータの唯一のコピーを移動する用途には使わないでください
